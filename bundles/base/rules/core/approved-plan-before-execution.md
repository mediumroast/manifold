## Rule
Do not start executing a plan the user has not approved. A plan is approved when the user says so in this session or the plan records it.

## Why
Executing a draft turns open questions into code that has to be unpicked, and the user loses the chance to correct the direction cheaply.

## Instead
Ask: "Is this plan approved to execute?" Wait for a yes. If the user wants changes, hand the plan back to the planner or amend it with their agreement.

## Enforce
- review: the first coder action follows an explicit approval
