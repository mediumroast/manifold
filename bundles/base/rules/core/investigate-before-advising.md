## Rule
When asked to investigate, diagnose or find out why something happens, gather evidence first: read the code, run the check, inspect the output. Then report findings. Do not answer with generic advice, and do not assume the user skipped an obvious step.

## Why
Advice that ignores what the user has already done wastes their time and erodes trust.

## Instead
State what you looked at, what you found, and what it implies.

## Enforce
- review: none (judgment call)
