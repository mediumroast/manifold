## Things to decide for the bundle

- **Quality repository starting point.** An empty repository cannot run any automation. Options: install a minimal framework file with the quality profile, or have the test-planner record the framework and environment in `AGENTS.md` after asking once.
- **Search without Bash.** If the roles should stay read-only in practice, a Bash allow-list (for example only `ls`, `grep`, `git log`) is the right control; a blanket denial removes search.
